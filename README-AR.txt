مهم:
لا ترفع ZIP مباشرة إلى GitHub؛ ارفع الملفات داخله.
لا تحذف أو تستبدل config.js أو v5-cloud.js، لأنهما مسؤولان عن إعداد اتصال قاعدة البيانات وتسجيل الدخول.
